BlueMart Python Local Server & .TXT Database
Created by ORG | UNK

HOW TO RUN:
1. Extract all files into a normal folder.
2. Double-click start-python-server.bat (or run: python server.py).
3. Open http://localhost:8000 on your PC, or open the Phone URL shown in the terminal on your phone over Wi-Fi.

DEFAULT ACCOUNTS (users.txt):
- orgunk / orgunk123   -> All Permissions (Read, Edit, Delete, Sales Wipe, Users)
- admin / admin123     -> Read & Edit Products + Restock
- staff / staff123     -> Employment (Read Only)
- customer / buy123    -> Customer (Buy Only)
